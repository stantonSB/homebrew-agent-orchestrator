# Homebrew Tap for Agent Orchestrator

A Homebrew Cask tap for installing [Agent Orchestrator](https://github.com/stantonSB/Agent-Orchestrator) — a desktop app for running parallel Claude Code terminal sessions with real-time status monitoring.

## Install

```bash
brew tap stantonSB/agent-orchestrator
brew install --cask agent-orchestrator
```

## Upgrade

```bash
brew upgrade --cask agent-orchestrator
```

## Uninstall

```bash
brew uninstall --cask agent-orchestrator
```

To also remove application data:

```bash
brew zap agent-orchestrator
```
